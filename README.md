### Short Description
A Python desktop simulator for classic CPU scheduling algorithms (FCFS, SJF/SRTF, Priority, Round Robin). Enter processes in a Tkinter GUI, run a selected algorithm, and inspect a matplotlib Gantt chart plus waiting/turnaround/response metrics. A comparison view runs the same workload across all algorithms.

### How to Run (starter)
```bash
pip install -r requirements.txt
python src/main.py
```
